# Caleb: Space Dominion para Android

Este repositorio genera automáticamente el APK del juego mediante GitHub Actions.

## Descargar el APK

1. Abra la pestaña **Actions** del repositorio.
2. Seleccione **Crear APK Android**.
3. Abra la ejecución más reciente y espere la marca verde.
4. En **Artifacts**, descargue **Caleb-Space-Dominion-APK**.
5. Descomprima el archivo descargado para obtener `app-debug.apk`.

La aplicación necesita conexión a Internet para cargar el juego.
